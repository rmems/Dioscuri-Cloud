# [TRAIN] Training-run metadata ingest (public-safe manifests)

**Override (2026-08-19):** Scope fully rewritten for **cloud AI model training setup**. Previous title: `[Oracle Cloud] Prototype tiny Rust telemetry ingestion service after OCI preflight`. Oracle Always Free service is not required.

## Goal

Record **training job metadata** (public-safe manifests) to the training bucket or a tiny ingest endpoint — not Oracle-specific telemetry for SAAQ.

## Scope

- Prefer **S3 PUT** of `training/manifests/<run_id>.json` from the training container on job completion.
- Optional: tiny service with `GET /healthz`, `POST /v1/training-run-manifest` (schema from #52).
- Synthetic example only in git (`examples/training-run-manifest.synthetic.json`).

## Non-goals

- No Oracle VM requirement.
- No raw telemetry with private paths.
- No production HA service.
