# [TRAIN] Experiment tracking for training runs

**Override (2026-08-19):** Scope fully rewritten for **cloud AI model training setup**. Previous title: `[Oracle] Deploy Database 23ai with AI Vector Search for shared RAG`. Oracle Autonomous DB 23ai is superseded.

## Goal

Track training **metrics and run history** in the artifact bucket (and optional lightweight tracker) — not a shared RAG vector database.

## Scope

- Per-run `metrics.json` or TensorBoard event files under `training/logs/<run_id>/`.
- Optional: `training/manifests/index.json` listing runs. Deduplicate on unique `run_id` (retries replace the existing record; do not append a second row for the same `run_id`). The file is append-only for **new** `run_id`s.
- Document how to compare two smokes (step loss, wall time, cost).

## Non-goals

- No Oracle Database 23ai / Autonomous DB.
- No shared RAG API for all IDE tools.
- No paid managed experiment platform unless cap-approved in this issue.
