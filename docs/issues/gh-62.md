# [TRAIN] One-script bootstrap for a training environment

**Override (2026-08-19):** Scope fully rewritten for **cloud AI model training setup**. Previous title: `[Skill] Grok GitHub Issues - Add Kilo MiMo Code Grok Build to HCL Docker setup`.

## Goal

One public-safe bootstrap path: verify AWS/HCP prerequisites, confirm bucket access, build/pull training image, run a **dry-run** (`nvidia-smi` on GPU node or SageMaker `DescribeTrainingJob` smoke).

## Scope

- Script or runbook under `scripts/` or `docs/training/` (no secrets in repo).
- Prerequisite checks (fail closed before later steps):
  1. HCP: org `Dioscuri-Cloud`, workspace `dioscuri-cloud-aws-training`, authenticated (`terraform login` or documented `hcp`/`tfc` check). If this fails, stop.
  2. AWS: `aws sts get-caller-identity` succeeds for the training account/profile.
  3. S3: probe the #47 training bucket (list prefix `training/`).
  4. Docker: build or pull the #61 training image.
  5. Optional dry-run: `nvidia-smi` on the GPU node or SageMaker `DescribeTrainingJob` / `ListTrainingJobs`.
- Document required env vars and where secrets live (HCP / local profile only).

## Non-goals

- No MCP/memory sync for agent swarm.
- No MiMo/Kilo/Grok IDE integration.
- No full training job (that's #59).
